Trang giả lập website khách

Trang này mô phỏng website của khách hàng có nhúng widget livechat Cluvix. Bong bóng chat xuất hiện ở góc.

Cách test tay

  1. Bảo đảm backend air chạy ở :8081 và đã build widget vào public/ (cd frontend/widget && npm run build:widget). Backend serve /widget.js, /widget.html, /api/* cùng origin.
  2. Tạo 1 site livechat (config omni-channel) và thêm origin của TRANG NÀY vào allowed_origins — ví dụ http://localhost:5500 (origin bạn serve file này). BE chỉ cho http với localhost/127.0.0.1.
  3. Serve thư mục dev/ qua static server ở đúng origin đã whitelist (vd npx serve -l 5500 frontend/widget/dev). MỞ bằng origin đó, KHÔNG mở bằng file:// (Origin null sẽ bị 403).
  4. Thay SITE_KEY_HERE + BACKEND_ORIGIN trong snippet dưới bằng giá trị thật (site_key nhận khi tạo site; BACKEND_ORIGIN = origin backend, vd http://localhost:8081).
  5. Bấm bong bóng → điền pre-chat (nếu bật) → chat. Mở inbox omnichat (staff) trả lời → tin hiện realtime ở widget; staff gõ → widget hiện “đang trả lời…”. Đóng widget, staff gửi tin → badge unread trên bong bóng.

Snippet nhúng

<script
  src="BACKEND_ORIGIN/widget.js"
  data-site-key="SITE_KEY_HERE"
  async></script>

Snippet thật do BE trả về khi tạo/sửa site (field snippet).
